# 🎓 Tutorials & Learning Resources

This document serves as a comprehensive index of tutorials and learning materials for the **Cal Poly Baja Electronics/Software Team**. Whether you are new to programming or looking to level up your skills in our specific tech stack, these resources will help you understand the core languages and tools used across our software and firmware projects.

---

## 1. Core Tools & Version Control

Before writing any code, you must understand how we collaborate, track changes, and manage our repositories.

- 🌿 **[Git & GitHub](GitLearningResources.md)**: Master the team's version control workflow. This covers branching, committing, rebasing, and opening Pull Requests without disrupting the team's codebase.

---

## 2. Programming Languages

These guides cover the fundamental syntax, conventions, and best practices for the languages used in our web applications (like PartSync and DataVis) and vehicle firmware.

- 🖥️ **[C++](CppLearningResources.md)**: Resources for learning C++, which is primarily used for programming our vehicle's microcontrollers and low-level firmware.
- 🌐 **[HTML](HtmlLearningResources.md)**: Basics of structuring web interfaces and components, essential for all our frontend applications.
- 🎨 **[CSS / SCSS](CssLearningResources.md)**: Guides on styling web applications, including the use of SCSS preprocessors for clean, scalable, and reusable design patterns.
- 📜 **[JavaScript & TypeScript](JsTsLearningResources.md)**: Core tutorials for JS and TS, the primary languages driving our web frontend, backend logic, and desktop tools. We heavily emphasize TypeScript for its type-safety.

---

## 3. Frameworks & Tools

This section provides tutorials for the specific frameworks, platforms, and utilities that power our software ecosystem. Understanding these tools is key to contributing to team projects.

- 🅰️ **[Angular](AngularLearningResources.md)**: Learn how to build dynamic, single-page web applications using the Angular framework. Covers components, services, and state management (Signals).
- 🐳 **[Docker](DockerLearningResources.md)**: Understand containerization and how we use Docker to ensure our software environments run consistently across everyone's local machines.
- ⚛️ **[Electron](ElectronLearningResources.md)**: Guides on using Electron to wrap our web-based applications into standalone, cross-platform desktop executables.
- 🟩 **[Node.js](NodeLearningResources.md)**: Resources for understanding the Node runtime, which powers our backend servers, API endpoints, and local development scripts.
- ⚡ **[Supabase](SupabaseLearningResources.md)**: Learn how to interact with our backend-as-a-service platform. These tutorials cover database management (PostgreSQL), authentication, and API usage.
