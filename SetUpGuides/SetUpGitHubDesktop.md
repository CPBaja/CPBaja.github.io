# Set Up GitHub Desktop for CPBaja

> **Audience:** Software & Electrons

This guide outlines the steps to set up **GitHub Desktop** and access the **CPBaja** repositories.

## Prerequisites

1.  **Create a GitHub Account:** If you don't have one, sign up on the [GitHub website](https://github.com).
2.  **Join the Organization:** Request or accept an invitation to join the **CPBaja Organization** on GitHub: [https://github.com/CPBaja](https://github.com/CPBaja).

---

## Installation and Sign-In

1.  **Download GitHub Desktop:**
    - Go to the official download page: [https://desktop.github.com/](https://desktop.github.com/).
    - Download and install the application for your operating system.
2.  **Open and Sign In:**
    - Launch the **GitHub Desktop** application.
    - When prompted, **Sign in to GitHub.com** using the account you created and joined the CPBaja organization with.

---

## Clone a Repository

1.  **Clone a Repository:**
    - Once signed in, click the **Clone a Repository** button or go to **File > Clone Repository**.
    - Select the **CPBaja** organization tab.
    - Choose the specific repository (e.g., `CPBaja/DataVisualizer`, `CPBaja/DAQ`) you want to work on.
    - Select the local path where you want the files to be saved (e.g., `C:\Users\YourName\Documents\GitHub\cpbaja-repo-name`).
    - Click **Clone**.
2.  **Start Working:**
    - The repository is now available on your local machine. You can view the files and start making changes.
