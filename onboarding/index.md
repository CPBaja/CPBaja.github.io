# 🚀 Software Subsystem Onboarding

Welcome to the **Cal Poly Baja SAE Software Subsystem** onboarding hub. This page will walk you through everything you need to know to become a productive contributor.

---

## 📋 Onboarding Overview

The onboarding process is designed so you can get up and running independently. Follow the steps below in order.

### Step 1 — Attend the Onboarding Meeting

All new members are required to attend a live or recorded onboarding session before working on any project. This meeting covers:

- Team structure and expectations
- Project overview and current sprint goals
- How to navigate the GitHub organization

> If you missed the live session, ask a lead for a recording link.

### Step 2 — Request Repository Access

After the onboarding meeting:

1. Locate the **access request form** (link provided at the onboarding meeting).
2. Submit your **GitHub username**.
3. Access is provisioned in batches — allow up to 48 hours.
4. You will receive a GitHub organization invitation at your registered email.
5. Accept the invitation to gain access to the [CPBaja GitHub organization](https://github.com/CPBaja).

> **Repository access is granted after setup verification and first-contribution readiness.** Complete your development environment setup and review the first-task guide before requesting access.

### Step 3 — Complete Development Environment Setup

Follow the general setup guides:

- **[Set Up GitHub Desktop](../SetUpGuides/SetUpGitHubDesktop.md)**
- **[Set Up VSCode](../SetUpGuides/SetUpVSCode.md)**
- **[Set Up Node.js](../SetUpGuides/SetUpNodeJS.md)**

Then complete the project-specific setup guide for the project you are joining.

### Step 4 — Read Your Project's Onboarding Docs

Each project has its own onboarding section. Work through the documentation top to bottom before picking up your first issue.

### Step 5 — Complete Your First Contribution

Follow the [First Contribution Guide](partsync/first-task.md) for your project. Your first pull request is the final verification step before you receive full contributor access.
