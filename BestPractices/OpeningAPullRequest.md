# Opening a Pull Request

This guide details how to open a pull request (PR), assign a reviewer, and update the project board.

---

## PR Naming Convention
Use the following naming format:

```
Issue #<number> <commit-style-message>
```

Example:

```
Issue #4 Add input validation to user registration
```

---

## Steps to Open a Pull Request
1. **Push your branch** to the remote repository.

2. **Open a pull request**:
   - Navigate to the repository's **Pull Requests** section.
   - Select your branch as the source.
   - Choose the correct target branch.
   - Set the PR title using the naming convention.
   - Add a concise description of the changes.

---

## Assigning a Reviewer
1. Open the PR page.
2. In the **Reviewers** panel, choose an appropriate reviewer.
3. Notify the reviewer if needed.

---

## Move the Issue to "In review"
After:
- Opening the pull request, and
- Assigning a reviewer

Update the project board:

1. Return to the **Project Board**.
2. Drag the issue card from **In progress** to **In review**.
3. Confirm the reviewer's avatar is displayed.
