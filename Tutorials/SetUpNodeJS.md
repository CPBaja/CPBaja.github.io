# Set Up Node.js

This guide covers installing Node.js and npm (Node Package Manager) on your local machine, which is essential for running our web applications and server-side JavaScript/TypeScript projects.

## 1. Installation

We recommend using the **LTS (Long-Term Support)** version of Node.js for maximum stability and compatibility with our projects.

1.  **Download Node.js:**
    - Go to the official Node.js download page: [https://nodejs.org/en/download/](https://nodejs.org/en/download/)
2.  **Run the Installer:**
    - Download and run the appropriate **LTS** installer for your operating system (Windows, macOS, or Linux).
    - During installation, ensure you select the option to install **npm** as well (it's usually included by default).

## 2. Verification

After the installation is complete, verify that both Node.js and npm are installed correctly by running these commands in your terminal or command prompt:

1.  **Check Node.js Version:**

    ```bash
    node -v
    ```

    _This should output the version number, e.g., `v18.17.1`._

2.  **Check npm Version:**
    ```bash
    npm -v
    ```
    _This should output the npm version number, e.g., `9.6.7`._
